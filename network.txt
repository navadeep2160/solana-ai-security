# What Each Component Does

## ML Layer

Answers:

```text id="n63qik"
Is something unusual happening?
```

Input:

```text id="4u2gc8"
TPS
Latency
Fork Rate
Slot Lag
Vote Success
Peer Count
```

Output:

```text id="sv24zg"
Anomaly Score = 0.93
```

It doesn't know why.

Just:

```text id="d2ph4z"
This looks abnormal.
```

---

## GNN Layer

Answers:

```text id="mr0n5m"
Where is the abnormality?
```

Input:

```text id="lixvv6"
Peer Graph
Vote Graph
Stake Graph
```

Output:

```text id="0g3kjg"
Possible Eclipse Attack

Validator:
abc123

Confidence:
87%
```

or

```text id="1w89p9"
Possible Validator Cartel
```

or

```text id="s13fx6"
Possible Partition
```

---

## RAG Layer

Answers:

```text id="zbjyc6"
What does this attack mean?
```

Retrieve:

```text id="epx86m"
Research Papers
Incident Reports
Validator Reports
Solana Documentation
```

Then explain:

```text id="qps3sy"
This resembles behaviors described in
the Eclipse Attack paper.
```

---

## Agentic Layer

Answers:

```text id="5vjlwm"
What should we do?
```

Example:

```json id="hbgvc0"

  "attack":"eclipse",
  "confidence":0.91
}
```

Agent generates:

```text id="6f26g8"

Restart gossip

Connect to additional validators

Monitor slot divergence
```
